# Design Requirements

Use black (#0B0B0B) as the primary background.

Use Royal Blue (#2563EB) and Metallic Gold (#F4B400) as accent colors.

Use glassmorphism cards with subtle blur.

Rounded corners (16–20px).

Soft shadows.

Blue and gold glowing hover effects.

Smooth scrolling.

Page transition animations.

Framer Motion animations.

Animated gradient backgrounds.

Custom cursor.

Loading screen with the SoRa logo.

Scroll progress bar.

Back-to-top floating button.

Dark theme only.

# SEO

Include proper meta title, meta description, Open Graph tags, favicon, semantic HTML5, accessibility best practices, lazy-loaded images, and optimized performance. The website should achieve a Lighthouse score above 95 for Performance, Accessibility, Best Practices, and SEO.

# Technical Requirements

Use **Next.js 15 + React + TypeScript + Tailwind CSS**.

Ensure the site is fully responsive across desktop, tablet, and mobile devices. Implement clean code architecture with reusable components, smooth animations, fast loading, and production-ready quality suitable for deployment on Vercel.
